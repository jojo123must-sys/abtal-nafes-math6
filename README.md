# أبطال نافس – رياضيات الصف السادس الابتدائي
مشروع ويب عربي تفاعلي مستوحى من التصميم المرجعي المرفق.
- 180 سؤالًا تدريبيًا مولدًا ومراجع الحساب برمجيًا وموزعًا على 10 فصول.
- خريطة فصول ومهارات، اختيار فصل دراسي، اختبار شامل أو تدريب مهارة.
- تصحيح فوري أو تصحيح عند التسليم، مؤقت، تنقل بين الأسئلة، تحليل نتيجة ومراجعة الشرح.
- يعمل محليًا بفتح index.html في متصفح حديث، ولا يحتاج إلى تثبيت.
ملاحظة: بنك الأسئلة تدريبي توضيحي من إعداد النموذج، وليس بنك وزارة التعليم أو اختبار نافس الرسمي. يجب على المعلمة مراجعته ومواءمته مع طبعة الكتاب المعتمدة قبل التقويم الرسمي.
